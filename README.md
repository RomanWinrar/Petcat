# 🐱 Pet The Cat 3D

Игра для PSP, в которой нужно гладить кота левым стиком. Кот собран из цветных кубиков, а рука гладит его сверху.

## Управление

| Кнопка | Действие |
|---|---|
| Левый стик ←→ | Гладить кота |
| ✕ | Дать коту рыбку |
| △ | Сменить цвет кота (рыжий, серый, чёрный, белый) |

## Особенности

- 3D-кот и рука, которая его гладит
- Сердечки при каждом поглаживании
- Шкала любви: хвост виляет быстрее, чем кот довольнее
- Настроения кота: обиженный, нормальный, довольный. Он моргает, зевает, мурчит, а при полной любви ложится на бок
- Счётчик рыбок
- Рекорд за минуту: раунд на 60 секунд стартует с первого поглаживания

## Интерфейс

- ❤ шкала любви (вверху слева)
- ⏱ таймер раунда (вверху справа)
- 🐟 счётчик рыбок (внизу слева)
- число по центру внизу: поглаживания в текущем раунде
- ⭐ число внизу справа: лучший результат

## Установка на PSP

Нужна PSP с кастомной прошивкой (CFW).

1. Открой вкладку **Actions** в этом репозитории и выбери последний успешный запуск.
2. В разделе **Artifacts** скачай `PetCat-PSP` и распакуй архив.
3. Скопируй папку `PSP` в корень карты памяти (если папка `PSP` там уже есть, объедини).
4. На PSP: **Игра → Карта памяти → Pet The Cat 3D**.

## Сборка

Игра собирается автоматически через GitHub Actions в контейнере `pspdev/pspdev`. Для ручной сборки нужен установленный [PSPSDK](https://pspdev.github.io/): выполни `make` в папке проекта, и получишь `EBOOT.PBP`.

## Файлы

- `main.c` — код игры
- `Makefile` — сборка через PSPSDK
- `.github/workflows/build.yml` — автоматическая сборка на GitHub
